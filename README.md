# Portfolio [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fdillionverma%2Fportfolio)

Built with next.js, [shadcn/ui](https://ui.shadcn.com/), and [magic ui](https://magicui.design/), deployed on Vercel.

# Features

- Setup only takes a few minutes by editing the [single config file](./src/data/resume.tsx)
- Built using Next.js 14, React, Typescript, Shadcn/UI, TailwindCSS, Framer Motion, Magic UI
- Includes a blog
- Responsive for different devices
- Optimized for Next.js and Vercel

# Getting Started Locally

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/dillionverma/portfolio
   ```

2. Move to the cloned directory

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Start the local Server:

   ```bash
   pnpm dev
   ```

5. Open the [Config file](./src/data/resume.tsx) and make changes

## Automated portfolio content

The project cards, featured merged PRs, and downloadable résumé are generated by
`.github/workflows/sync-portfolio.yml`. The workflow runs daily, can be started
manually, and accepts a `profile-readme-updated` repository dispatch from the
`blackdragoon26/blackdragoon26` profile repository.

Required profile-repository configuration:

- `PORTFOLIO_SYNC_TOKEN`: a fine-grained personal access token that can dispatch
  workflows to `blackdragoon26/muchBetterPortfolio`.

Optional portfolio-repository configuration for Google Drive:

- `DRIVE_SERVICE_ACCOUNT_JSON`: the full Google service-account JSON document.
- `DRIVE_FOLDER_ID`: a Drive folder shared with that service account as Editor.

The merged-PR filter defaults to repositories with at least 300 stars. Override
it with the portfolio repository variable `PORTFOLIO_MIN_REPO_STARS`. Generated
JSON, preview images, résumé appendix, and PDF are committed by the workflow so
the website remains static and requires no application backend.
